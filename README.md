# WhiteLabel

A real estate platform built entirely on Microsoft Azure, demonstrating production-grade architecture using Azure Static Web Apps, Container Apps, Cosmos DB for PostgreSQL, Key Vault, Entra ID, and Defender for Cloud.

WhiteLabel exists to prove a single point: Azure alone, with no third-party infrastructure, can carry a full modern web application from hosting to security without compromise. Built in the context of the Nedscaper, Microsoft Security Partner of the Year 2025, this project mirrors that same philosophy. Security is not bolted on after the fact, it is built in from the first commit.
